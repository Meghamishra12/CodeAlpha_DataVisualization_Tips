# Restaurant Tips Data Visualization - CodeAlpha Internship (Task 3)

Data visualization on the restaurant tips dataset as part of the CodeAlpha Data Analytics Internship.

## Objective
To understand when and how customers tip more, using charts and clear insights.

## Dataset
- Tips dataset (seaborn), 244 orders, 7 columns
- Columns: total_bill, tip, sex, smoker, day, time, size
- No missing values
- Added column: tip_pct (tip as a percentage of the bill)

## Visualizations and Insights

### 1. Average Bill by Day
![Avg Bill by Day](charts/1_avg_bill_by_day.png)
**Insight:** Sunday has the highest average bill and Friday the lowest. Weekend bills are higher than weekday bills.

### 2. Bill vs Tip
![Bill vs Tip](charts/2_bill_vs_tip.png)
**Insight:** Tip increases as the bill increases. Most bills are between $10 and $25, and large bills are mostly Dinner orders.
